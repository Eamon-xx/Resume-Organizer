## Same Project, Different Responsibility

Project: Resume Organizer, a tool that scans local projects and turns evidence into resume project experience drafts.

### Solo Owner

```text
独立设计并实现本地项目经历生成工具，完成项目扫描、职责确认、事实卡构建与简历段落生成流程；通过证据等级和待确认问题机制，避免将项目整体能力误写为个人贡献。
```

### Module Owner

```text
负责项目中的事实提取与个人贡献归因模块，设计 Project Fact Card / Personal Contribution Card 输出结构，并结合 Git、README、目录结构等证据标记 Confirmed、Evidence、Inferred、Missing 四类结论。
```

### Contributor

```text
参与本地项目扫描能力建设，补充 Git 作者分布、依赖文件识别和输出结构校验逻辑，帮助生成流程在多人项目场景下更准确地区分项目背景与个人贡献。
```

## Weak vs Strong

Weak:

```text
参与简历生成项目，使用 Python 和 AI 技术，实现项目总结功能。
```

Stronger:

```text
负责项目经历生成流程设计，先提取本地项目事实与职责边界，再根据目标岗位生成保守版本、技术版本和 JD 匹配版本，降低大项目中贡献归因不清导致的简历表述风险。
```
