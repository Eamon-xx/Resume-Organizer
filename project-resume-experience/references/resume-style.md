# Resume Style

Default to conservative Chinese resume wording. Keep claims specific, evidence-backed, and role-targeted.

## Bullet Shape

Prefer:

```text
负责/设计/实现 + 具体模块 + 技术方法 + 解决的问题 + 可证实结果
```

Avoid:

```text
参与项目开发，使用若干技术，实现多个功能，提升用户体验。
```

## Role Emphasis

Backend:
- API design, data modeling, auth, async jobs, caching, reliability, deployment.

Frontend:
- Component design, state management, interaction flow, rendering performance, engineering quality.

AI Application:
- Information extraction, prompt design, structured output, retrieval, evaluation, automation workflow.

Full Stack:
- End-to-end delivery, interface contracts, data flow, integration, deployment.

Data / Infra:
- Pipelines, scheduling, observability, quality checks, scalability, cost or stability.

## Seniority Framing

Intern / campus:
- Emphasize concrete implementation, learning depth, engineering discipline, tests, and delivery.

Junior:
- Emphasize independently owned modules, clear problem solving, maintainability, and collaboration.

Mid-level:
- Emphasize design tradeoffs, cross-module ownership, reliability, performance, and delivery outcomes.

Senior:
- Emphasize system design, technical direction, risk reduction, team leverage, and measurable impact.

## Metrics

Only use numbers when they are measured or confirmed.

Allowed:
- "将解析耗时从 3.2s 降至 1.1s" when measured.
- "支持约 500 份样例简历批量处理" when confirmed.

Conservative alternatives:
- "减少重复人工整理"
- "提升生成结果的一致性"
- "降低后续维护成本"
- "支撑批量处理流程"

## JD-Matched Rewrite

When a JD is provided:

1. Extract 3-5 relevant JD signals.
2. Map only confirmed project contributions to those signals.
3. Rewrite emphasis without adding unsupported tools, metrics, or ownership.
4. Keep one version general enough for the base resume and one version tailored to the JD.

## Final Chinese Format

```text
项目名称｜角色｜时间
- 负责...，基于...实现...，解决...
- 设计...，通过...提升/支撑...
- 与...协作/联调...，完成...
```
